# Car Sales Data Visualization Project

## Project Overview

This project analyzes a modified car sales dataset using **Microsoft Excel**. The goal of the project is to practice creating charts and visual summaries that make car sales data easier to understand and communicate.

The workbook includes multiple chart-focused worksheets and a source data worksheet. The project demonstrates how Excel can be used to explore sales trends, compare vehicle attributes, and present data visually for business analysis.

## Dataset

The dataset is based on a modified subset of a public car sales dataset from Kaggle. It contains information about different car manufacturers, models, pricing, sales, resale value, vehicle type, engine size, horsepower, fuel efficiency, and other automotive features.

## Charts Created

### Histogram Chart

A histogram chart is used to show the distribution of numerical data. In this project, it helps identify how values such as car prices, sales, or other numeric features are spread across different ranges.

### Scatter Chart

A scatter chart is used to compare the relationship between two numeric variables. This helps identify possible trends, patterns, or correlations in the car sales dataset.

### Sunburst Chart

A sunburst chart is used to show hierarchical data. It helps display grouped relationships in the dataset, such as manufacturer, vehicle type, or other category-based breakdowns.
